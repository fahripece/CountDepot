Webhooks

CountDepot can POST JSON payloads to your endpoint when events occur. Manage webhooks at /webhooks.

{
  "event": "item.checked_out",
  "created_at": "2026-04-13 14:23:00",
  "data": {
    "id": 42,
    "name": "ThinkPad X1 Carbon",
    "checked_out_by": "Alice",
    "job_ref": "JOB-2026-099"
  }
}

Verify signature: HMAC-SHA256(secret, raw_body) must match X-CountDepot-Signature header.

Zapier Integration

Connect CountDepot to 6,000+ apps via Zapier using webhooks as your trigger.

Step 1: In Zapier, create a new Zap → Trigger → Webhooks by Zapier → Catch Hook. Copy the webhook URL.
Step 2: In CountDepot, go to Webhooks → Add Webhook. Paste the Zapier URL and choose your events.
Step 3: In Zapier, test the trigger, then build your action (Slack message, Google Sheet row, email, etc.).
