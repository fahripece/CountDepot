First login guide
Welcome to CountDepot.

This quick tour shows the core workflow: organize categories, define products, add inventory, and split items across sites.

1. Start with categories

Categories organize inventory and define custom fields for groups like Tools, Parts, Supplies, or Equipment.

Create categories from Settings.
Add fields like asset tag, warranty, or inspection date.
Open Categories

2. Create products

Products are reusable templates. Create a product once, then add individual units or quantities from it.

Set default category, cost, sale price, and SKU rules.
Bulk add similar items with different serial numbers.
Open Products

3. Add inventory items

Items are the actual things you own. Add serials, quantities, shelf/bin, condition, cost, and product details.

Add single items, quantity stock, or bulk serial-number units.
Use the bottom action bar for edit, reserve, clone, and checkout.
Add First Item

4. Use sites and locations

Sites separate inventory by warehouse, truck, client, room, branch, or jobsite.

Create sites from the Sites page.
Assign users to sites for location-restricted access.
Open Sites

5. Scan, reserve, and invite your team

Use the mobile page for field work, reservations to protect job inventory, and Admin to invite workers.

Use /mobile for scanner-first check in/check out.
Use Reservations when inventory is promised for a future job.
Invite workers from Admin with only the permissions they need.
Open Mobile Scanner
