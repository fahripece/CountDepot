First login guide
Welcome to CountDepot.

This guided tour opens each core page for you and explains what to do there.

{% if can_manage_settings %}

1. Start with categories

Categories organize inventory and define custom fields for groups like Tools, Parts, Supplies, or Equipment.

Create categories from Settings.
Add fields like asset tag, warranty, or inspection date.
Open Categories

2. Create products

Products are reusable templates. Create a product once, then add individual units or quantities from it.

Set default category, cost, sale price, and SKU rules.
Bulk add similar items with different serial numbers.
Open Products
{% endif %} {% if session.get('role') != 'viewer' %}

3. Add inventory items

Items are the actual things you own. Add serials, quantities, shelf/bin, condition, cost, and product details.

Add single items, quantity stock, or bulk serial-number units.
Use the bottom action bar for edit, reserve, clone, and checkout.
Add First Item
{% endif %}

4. Use sites and locations

Sites separate inventory by warehouse, truck, client, room, branch, or jobsite.

Create sites from the Sites page.
Assign users to sites for location-restricted access.
Open Sites
{% if session.get('role') != 'viewer' %}

5. Reserve inventory for jobs

Reservations protect stock that is promised for a client, job, or future date so workers see conflicts before using it.

Track reserved, available, and total quantity.
Use warnings and overrides when work conflicts with reservations.
Open Reservations
{% endif %} {% if session.get('role') == 'admin' or 'view_docs' in user_perms %}

6. Add SOPs and team docs

SOPs keep receiving steps, checkout rules, safety notes, and field procedures next to the inventory system.

Create docs categories like Receiving, Safety, or Field Work.
Give some users view-only docs access and others create/delete permission.
Open SOPs & Docs
{% endif %} {% if session.get('role') != 'viewer' %}

7. Use mobile scanner mode

The mobile page is the simplified worker flow for scan/search, check in, check out, and reservations.

Use it from phones and handheld scanners.
Keep billing and admin-heavy tools off the worker screen.
Open Mobile Scanner
{% endif %} {% if session.get('role') == 'admin' %}

8. Invite users and set permissions

Admin controls who can view, create, edit, delete, reserve, manage docs, and access sites.

Invite workers with the minimum permissions they need.
Promote trusted users to admin when they need full workflow control.
Open Users & Permissions
