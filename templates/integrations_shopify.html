1. In your Shopify Admin go to Settings → Apps and sales channels → Develop apps.
2. Create a new app. Under Admin API access scopes enable: read_products write_products read_inventory write_inventory read_orders.
3. Click Install app and copy the Admin API access token.
4. For real-time order sync, add a webhook in Shopify for the Order payment event pointing to {{ request.host_url }}integrations/shopify/webhook.
